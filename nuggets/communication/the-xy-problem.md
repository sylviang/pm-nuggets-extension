# The XY Problem

_Last updated: 2025-12-16_

The XY Problem is a communication anti-pattern where someone asks about their attempted solution (Y) rather than their actual problem (X). This leads to wasted effort solving the wrong problem, while better solutions remain hidden.

How it happens: You want to achieve X. You think Y might help, so you ask "How do I do Y?" without mentioning X. Helpers can only suggest ways to do Y, missing that solution Z might be far better for X.

Classic example from product management:
- User asks: "How can I export data to CSV every day?"
- Real problem: They need to share metrics with their team
- Better solution: Create a dashboard with live data instead

Why it matters:
- Wastes time solving the wrong problem
- Obscures the real user need behind assumed solutions
- Prevents discovery of superior alternatives
- Common in customer interviews when users suggest features

How to avoid it as a PM:
- Ask "What are you trying to accomplish?" before jumping to solutions
- Dig into the "why" behind feature requests
- Document the root problem, not just the proposed solution
- Frame questions as: "My goal is X; I tried Y but..."
